# UI-UX-Experiment2

## Aim:
To design and develop a food ordering mobile application (Quick Bite) that allows users to easily search, order, and get discounts on their favorite food items with login/signup functionality.

## Algorithm:
1. Start

2. Launch the **SS Burger Shop** app/website.

3. On the home screen:

   * Display the burger menu with prices.
   * Highlight special offers (e.g., 50% OFF).
   * Show clear **Order Now** buttons under each item.

4. Select a burger (e.g., Veg Burger, Chicken Burger, Cheese Burger).

5. Navigate to the **Login/Signup screen**:

   * If the user has an account → enter Email/Password and click **Login**.
   * If new → choose **Google Sign-in** or click **Signup** to create an account.

6. Authenticate user credentials.

7. Once logged in → confirm selected burger, apply discounts, and proceed to checkout.

8. Complete payment and place the order.

9. End
